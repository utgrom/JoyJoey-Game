# Joy Joey

Prototipo de juego de acción lateral en **Unity 6000.4.6f1**. El Circo onírico sirve para probar la movilidad de Joey y practicar combos contra un muñeco de entrenamiento.

## Abrir el proyecto

1. Añadí esta carpeta a Unity Hub y abrila con la versión indicada en `ProjectSettings/ProjectVersion.txt`.
2. Abrí `Assets/JoyJoey/Scenes/Arranque.unity` y pulsá **Play**.
3. Desde el menú principal, elegí **Circo onírico** para practicar o **Empezar juego** para entrar al nivel de prototipo.

## Controles de juego por defecto

| Acción | Teclado | PlayStation | Xbox |
| --- | --- | --- | --- |
| Dirección | WASD | Stick izquierdo o cruceta | Stick izquierdo o cruceta |
| Salto | Espacio | Cruz | A |
| Ataque básico | J | Cuadrado | X |
| Ataque Rag | K | Triángulo | Y |
| Trick | L | Círculo | B |
| Dash | Mayús | R1 | RB |
| Transformación | H | L1 | LB |
| Traje anterior / siguiente | Q / E | L2 / R2 | LT / RT |
| Pausa | Esc | Start | Menu |

En **Opciones → Controles** podés cambiar las asignaciones de juego de teclado y ratón o de mando. El último dispositivo usado determina qué perfil se muestra. La zona muerta del stick izquierdo se puede ajustar desde ambos perfiles.

## Build para Windows

En **File → Build Profiles → Windows**, comprobá que **Arranque** sea la primera escena y pulsá **Build**. Elegí una carpeta vacía y conservá juntos todos los archivos que genere Unity. Los binarios de prueba y la documentación interna se guardan fuera del historial de Git.
